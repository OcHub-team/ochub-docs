## 対応アプリ

| アプリ | 書き込み方式 | MCP | スキル | 固有機能 |
| --- | --- | --- | --- | --- |
| Claude Code | 現在の接続を切り替え | 対応 | 対応 | プラグイン、役割モデル、セッション |
| Claude Desktop | 現在の接続を切り替え | 非対応 | 非対応 | 公式／サードパーティー接続 |
| Codex | 現在の接続を切り替え | 対応 | 対応 | OAuth、モデルカタログ、履歴 |
| Cherry Studio | Deep Link で確認してインポート | 非対応 | 非対応 | プロバイダーと API Key のインポート |
| Grok Build | 現在の接続を切り替え | 対応 | 非対応 | プロファイル、API バックエンド |
| Kimi Code | 現在の接続を切り替え | 非対応 | 非対応 | プロバイダー、モデル、上限、機能 |
| OpenCode | 複数接続の共存 | 対応 | 対応 | 複数モデル、セッション、OMO |
| OpenClaw | 複数接続の共存 | 非対応 | 非対応 | デフォルトモデル、ツール、環境 |
| Hermes | 複数接続の共存 | 対応 | 対応 | モデル、レート制限、メモリ |

切り替え方式は 1 つの実接続を重視します。共存方式は複数をツールへ書き込み、ツールまたは
OcHub から選択します。
Cherry Studio は独自の確認ダイアログを開き、アプリのデータベースへ直接書き込みません。

## 既定パス

| 内容 | 既定場所 |
| --- | --- |
| OcHub データ | `~/.ochub/` |
| OcHub データベース | `~/.ochub/ochub.db` |
| ユーザーアプリプラグイン | `~/.ochub/apps/*.toml` |
| cc-switch 移行元 | `~/.cc-switch/` |
| Claude Code | `~/.claude/`、MCP は通常 `~/.claude.json` |
| Codex | `~/.codex/` |
| Grok Build | `~/.grok/` |
| Kimi Code | `~/.kimi-code/` |
| Cherry Studio | OcHub はデータディレクトリへ書き込まず、`cherrystudio://` でインポート |
| OpenCode | `~/.config/opencode/` |
| OpenClaw | `~/.openclaw/` |
| Hermes | `~/.hermes/` |
| Claude Desktop（macOS） | `~/Library/Application Support/Claude/` と `Claude-3p/` |
| Claude Desktop（Windows） | `%LOCALAPPDATA%\\Claude\\` と `Claude-3p\\` |

アプリ設定のカスタムディレクトリがこの表を上書きします。変更後は OcHub を再起動します。

## 接続状態

| 状態 | 意味 |
| --- | --- |
| 現在 | OcHub で選択中の接続。クライアントの再読み込みを証明するものではない |
| 追加済み | ツールには存在するが現在ではない |
| 直接接続 | ツールがプロバイダーへ直接接続 |
| モデルプロバイダーモード | ツールが OcHub ローカルゲートウェイへ接続 |
| 適用済み | モデルプロバイダーがアプリへ書き込み済み |
| 無効 | 設定は残るが適用・ルーティング不可 |
| 下書き保存済み | 編集内容を独立して保存。正式な接続と対象ファイルは未変更 |
| 設定書き込み済み | 対象ファイルの書き込み完了。クライアントの読み込み・通信検証は別途確認 |
| アプリ内の確認待ち | 外部インポートが未確認で、下書きを保持 |

## モデルプロバイダーのインターフェース

| インターフェース | 代表的なクライアント |
| --- | --- |
| Anthropic Messages | Claude 互換 |
| OpenAI Chat | Chat Completions 互換 |
| OpenAI Responses | Responses API 利用クライアント |

自動ルーティングはネイティブインターフェースを優先し、モデルまたはインターフェース障害時に
別の有効な候補を試します。変換で上流に存在しないモデルや機能を追加することはできません。

## 最小 MCP JSON

stdio：

```json
{
  "type": "stdio",
  "command": "my-mcp",
  "args": ["--stdio"]
}
```

SSE：

```json
{
  "type": "sse",
  "url": "https://example.com/sse"
}
```

設定は JSON オブジェクトです。詳細フィールドは MCP サーバーと対象アプリの両方に依存します。

## 用語

<dl>
  <dt>編集下書き</dt>
  <dd>未完成の項目や不正な原文を独立して保存した編集内容。正式な接続と対象設定は明示的に適用するまで変わりません。</dd>

  <dt>アプリ</dt>
  <dd>Claude Code や Codex など、OcHub が設定を管理する AI ツール。</dd>

  <dt>接続</dt>
  <dd>API、公式ログイン、モデルサービスの接続情報一式。</dd>

  <dt>直接接続</dt>
  <dd>OcHub ゲートウェイを通らず、ツールからプロバイダーへ送る接続。</dd>

  <dt>モデルプロバイダー</dt>
  <dd>プロトコル変換、モデルマッピング、インターフェース候補の再試行に使う上流設定。</dd>

  <dt>設定ドリフト</dt>
  <dd>OcHub が読み込んだ後で、実設定が外部から変更された状態。</dd>

  <dt>課金モデル</dt>
  <dd>使用量の価格参照に使うモデル。リクエストまたはレスポンス由来。</dd>

  <dt>プロファイル</dt>
  <dd>リモート同期内で複数の OcHub データを分離する論理名。</dd>
</dl>

## セキュリティ

- API キー、OAuth トークン、個人セッションを問題報告や画像へ公開しない。
- ローカルゲートウェイをインターネットへ直接公開しない。
- 信頼できる MCP コマンドとスキルだけを実行する。
- データベース上書き、セッション／接続の削除の前にバックアップする。
- OcHub と別の管理ツールで同じファイルへ同時に書き込まない。
