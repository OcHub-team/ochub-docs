デバイス全体の項目は「設定」、画面の配色は「テーマ」にあります。アプリページ
右上の**アプリ設定**は、その AI ツールだけに作用します。

## サイドバーでページを探す

上部には**概要**、**プロバイダーとルート**、**使用量**、**セッション**があります。
**アプリ接続**を展開すると管理対象アプリを開けます。折りたたんでもナビゲーションの項目が
隠れるだけで、管理は無効になりません。**拡張機能**には MCP とスキル、**環境と保守**には
プロキシ、リモートノード、保守ツールがあります。通知センターとテーマ・設定・情報の
アイコンは下部に固定され、ナビゲーションをスクロールしても表示されます。

## フォームから安全に移動する

接続、同期、プロキシ、MCP、ルート、テーマ、アプリのディレクトリ、高度な設定の未保存の変更は、ページや管理対象の環境の切り替え、ウィンドウを閉じる前に確認されます。書き込み中は完了を待ちます。通常のフォームでは**編集に戻る**を選び、そのページの保存ボタンで保存するか、**破棄して続行**を選びます。接続の下書きには専用の**下書きを保存**操作があります。

接続が切れても、入力中のフォームはメモリに残ります。同じ検証済みノードへ再接続すると編集を続けられ、別のノードには送信されません。通常のフォームはアプリの再起動後には復元されないため、終了前に保存してください。更新後の再起動にも同じ確認が適用されます。

ドロップダウンでは**上下キー**と **Home/End** で移動し、**Enter/Space** で選択、**Escape** で取り消します。**Tab** はリストを閉じて次の項目へ移動します。開いているボタンをもう一度クリックすると閉じ、別のダイアログが開くと古いリストは閉じます。通知センターを開いている間、保存ショートカットは背後のフォームを送信しません。

## 通知を読む

短い通知は右上に表示されます。長い診断は**詳細**にまとめられ、通知がページを大きく覆うことは
ありません。マウスを重ねるかキーボードでフォーカスすると自動消去が一時停止します。
通知を閉じても、サイドバー下部の**通知センター**から同じ項目を確認できます。

通知センターには今回の起動中の最近の通知を最大 64 件保持します。項目を開いて内容を読み、
必要なら**詳細をコピー**します。**すべて既読にする**と**既読を削除**はリストの管理用です。
閉じたり読んだりしても、元の問題が解決したことにはなりません。履歴はアプリ再起動後には保持されず、
操作の監査ログでもありません。フィールドのエラーや接続の下書き保存・適用結果はエディター内に
表示され、その場で対応できます。

## 一般設定

| 設定 | 効果 |
| --- | --- |
| 言語 | システムに従うか、対応言語を固定 |
| 優先ターミナル | セッションを開くターミナル。「自動」は環境を検出 |
| ログイン時に起動 | システムログイン後に OcHub を起動 |
| ウィンドウを表示せず起動 | ログイン時起動が有効な場合だけ作用 |
| ウィンドウを閉じても実行 | メイン画面を閉じ、バックグラウンドを維持 |
| システムメニュー切り替え | macOS メニューバー／Windows タスクバーに接続を表示 |

設定が使えない場合は、その下に表示される理由を確認します。例えば、サイレント起動には
ログイン時起動を先に有効にする必要があります。最後に残った管理対象アプリにも、
**管理を無効にする**ボタンが使えない理由が表示されます。

サイレント起動と同時にバックグラウンド動作とシステムメニューを無効にすると、画面を
開き直しにくくなります。少なくとも 1 つの表示可能な入口を残してください。

## キーボード操作

**Tab** と **Shift+Tab** でコントロール間を移動し、**Enter** または **Space** でフォーカス
中のボタンやチェックボックスを操作します。テキストエディターでは固有の編集キーが使われます。

**Escape** でワークスペースメニュー、生の設定エディター、リモート接続ダイアログを閉じます。
接続の編集中にワークスペースメニューを閉じても、接続フォームは開いたままです。
処理の実行中はダイアログを閉じられない場合があります。

入力欄ではコピー、貼り付け、切り取り、全選択、元に戻すが使えます。macOS では
**Option+←/→** で単語単位、**Command+←/→** で行頭・行末へ移動し、**Shift** を加えると
選択範囲を広げます。**Option+Backspace** は前の単語、**Command+Backspace** は行頭まで
削除します。Windows と Linux では **Ctrl+←/→**、**Ctrl+Backspace**、**Home/End** を
使います。生の設定エディターでは **Tab** はインデントに使われます。

## アプリとプラグイン

**設定 → アプリとプラグイン**を開きます。

- 各行にアプリ名、提供元（**組み込みアダプター**または**ユーザープラグイン**）、管理状態が
  表示されます。
- 各行の**管理を有効にする**／**管理を無効にする**ボタンで OcHub による管理を切り替えます。
  サイドバーとシステムメニューの表示にも反映されます。
- 少なくとも 1 アプリの管理を有効にしておきます。無効化しても接続データと現在の設定
  ファイルは保持されます。
- **プラグインフォルダーを開く**でローカルの manifest 保存先を開きます。既定は
  `~/.ochub/apps/` です。`.toml` の追加・編集後に**プラグインを再読み込み**し、
  同じページでエラーを確認します。
- 設定 schema を持つローカルの宣言型プラグインはアプリ一覧に表示され、同じ基本・詳細・
  設定ファイル・下書きエディターを利用します。対応するローカルアプリの追加にはプラグインの
  インストールだけが必要で、OcHub 本体の変更は不要です。
- 宣言された機能だけを表示します。ネットワーク検査、公式ログイン、専用保守などは自動追加
  されません。未知のキーは保持されますが、書式・コメントの維持は形式に依存します。
- プラグイン変更後はエディターを開き直して項目を確認します。下書きはアダプターの版を保持し、
  編集中にアダプターを変更した場合、旧下書きの直接適用は拒否されます。
- リモートの項目一覧だけでは完全な codec は提供されません。デスクトップが codec を知らない
  リモートプラグインでは構造化編集は使えません。対応するローカル宣言型プラグインとは異なります。

## テーマを切り替える

1. **テーマ**を開きます。
2. システムに従う、常にライト、常にダークを選びます。
3. テーマカードの**適用**を選びます。
4. システムに従う場合、同じテーマのライト／ダークバリアントを切り替えます。

## デスクトップごとの外観

OcHub は本機で使える UI フォントと等幅フォントを選びます。Windows ではシステムの
背景ぼかしを維持します。Linux では、背後の文字が読みやすさに影響しないよう、ぼかし
テーマを不透明な背景で表示します。明示的に透明を選んだテーマは透明のままです。
Linux のデスクトップ環境がタイトルバーを提供する場合、二重には表示しません。

## インポート、エクスポート、編集

- 組み込みテーマは読み取り専用です。**複製して編集**でユーザーコピーを作ります。
- 名前、作者、説明、マテリアル、透明度、カラートークンを編集できます。
- **プレビューを更新**は下書きをアプリ全体へ一時適用し、保存またはキャンセルで終了します。
- ライトとダークを個別に設定し、文字、アクセント、表面の可読性チェックを通します。
- エクスポートで共有し、インポートは両バリアントを検証してから追加します。

色は完全な `#RRGGBB` を使います。コントラスト不足のエラーが出たら、示された前景色または
背景色を 4.5:1 以上になるまで調整します。

## 元に戻す

- プレビューが合わなければキャンセルし、以前のテーマへ戻します。
- 組み込みテーマは削除できません。
- ユーザーテーマの削除はローカルファイルを完全に消します。必要なら先にエクスポートします。
