Device-wide options live under Settings, while interface colors live under
Theme. **App settings** in the upper-right corner of an app page affects
only that AI tool.

## Find pages in the sidebar

The top navigation contains **Overview**, **Providers & routes**, **Usage**, and
**Sessions**. Expand **App connections** to open a managed app; collapsing this
list only hides its navigation entries and does not disable management.
**Extensions** groups MCP and Skills. Proxy, remote nodes, and maintenance tools
are under **Environment**. Notifications and the Themes, Settings, and About icons
stay at the bottom even when the navigation list scrolls.

## Read notifications

Brief notifications appear in the upper-right area. Long diagnostics stay behind
**Details** instead of expanding the toast over the page. Hovering or focusing a
notification pauses its automatic dismissal. Closing the toast leaves its entry
in **Notifications**, accessible at the bottom of the sidebar.

The center retains up to 64 recent notifications from this app launch. Open an
entry to read its detail and choose **Copy details** when needed. **Mark all read**
and **Clear read** manage this list; closing or reading a notification does not
resolve the underlying issue. History is not saved across app restarts and is not
an operation audit log. Field errors and connection draft/application results
remain in their editor, where you can act on them.

## General settings

| Setting | Effect |
| --- | --- |
| Language | Follow the system or choose a supported language |
| Preferred terminal | Terminal used to open sessions; Auto detects the local environment |
| Launch at login | Start OcHub after system login |
| Start without showing the window | Applies only when launch at login is enabled |
| Keep running after closing the window | Close the main window but keep the background process |
| System-menu quick switching | Show connection shortcuts in the macOS menu bar or Windows taskbar |

When a setting is unavailable, read the reason shown beneath it. For example,
enable launch at login before using silent startup. The last managed app also
explains why its **Disable management** button is unavailable.

If you combine silent startup with background operation and system-menu
shortcuts both disabled, reopening the main window becomes inconvenient. Keep
at least one visible entry point.

## Keyboard navigation

Use **Tab** and **Shift+Tab** to move between controls. Activate a focused button
or checkbox with **Enter** or **Space**. Text editors keep their own editing keys.

Use **Escape** to close the workspace menu, raw configuration editor, or remote
connection dialog. Closing the workspace menu while editing a connection keeps
the connection form open. An operation in progress may prevent its dialog from
closing.

Inputs support copy, paste, cut, select all, and undo. On macOS, use
**Option+Left/Right** to move by word and **Command+Left/Right** to move to the
start or end of a line; hold **Shift** to extend the selection. Use
**Option+Backspace** to delete the previous word or **Command+Backspace** to
delete to the start of the line. Windows and Linux use **Ctrl+Left/Right**,
**Ctrl+Backspace**, and **Home/End**. **Tab** inserts indentation in the raw
configuration editor.

## Manage apps and plugins

Open **Settings → Apps and plugins**:

- Each row shows the app name, its source (**Built-in adapter** or **User
  plugin**), and its management status.
- Use **Enable management** or **Disable management** on that row. These
  actions control whether OcHub can manage the app, including its sidebar and
  system-menu entries.
- Keep management enabled for at least one app. Disabling preserves connection
  data and the tool's current configuration files.
- **Open plugin folder** opens the local manifest directory, normally
  `~/.ochub/apps/`. After adding or editing a `.toml` manifest, select
  **Reload plugins**. Load errors appear on this page.
- Local declarative plugins with a configuration schema appear in app navigation
  and use the same General, Advanced, Config files, and draft editor. Adding a
  supported local app requires installing its plugin, without changing OcHub itself.
- Only declared capabilities are exposed. Network probes, official login, or
  special maintenance actions do not appear automatically. Unknown keys are
  retained; exact formatting and comment preservation depend on the format.
- Reopen the editor after changing a plugin and review its fields. Drafts retain
  their adapter revision; replacing an adapter while editing blocks direct
  application of the older draft.
- A remote field list does not supply a full codec. Remote plugins whose codecs
  are unknown to the desktop cannot use structured editing. This limitation does
  not apply to supported local declarative plugins.

## Switch themes

1. Open **Theme**.
2. Choose Follow system, Always light, or Always dark.
3. Select **Apply** on a theme.
4. Follow system switches between that theme's light and dark variants.

## Appearance across desktops

OcHub selects available local interface and monospace fonts. Windows retains
system background blur. On Linux, a blurred theme falls back to an opaque
background so content behind the window does not reduce readability. Themes
explicitly set to transparent remain transparent. When the Linux desktop
provides a title bar, OcHub does not add a second one.

## Import, export, and edit

- Built-in themes are read-only. Use **Duplicate and edit** to create a user
  copy.
- A user theme can change its name, author, description, material, opacity, and
  color tokens.
- **Update preview** temporarily applies the draft across the app; Save or
  Cancel ends the preview.
- Configure light and dark variants independently and pass readability checks
  for text, accent colors, and surfaces.
- Export shares a theme file. Import validates both variants before adding it
  to the library.

Use full `#RRGGBB` values. If saving reports insufficient contrast, adjust the
foreground or background named in the error until the ratio is at least 4.5:1.

## Restore

- Cancel an unwanted preview to return to the previous theme.
- Built-in themes cannot be deleted.
- Deleting a user theme removes its local file permanently. Export it first if
  you may need it again.
