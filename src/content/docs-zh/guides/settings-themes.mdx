设备级选项集中在“设置”，界面配色集中在“主题”。应用页右上角的“应用设置”只影响
当前 AI 工具，不要和设备级设置混淆。

## 通用设置

| 设置 | 作用 |
| --- | --- |
| 语言 | 跟随系统，或固定为受支持语言 |
| 首选终端 | 打开会话时使用的终端；“自动”会探测本机环境 |
| 开机启动 | 登录系统后启动 OcHub |
| 启动时不显示窗口 | 仅在开机启动开启时生效 |
| 关闭窗口后继续运行 | 关闭主窗口但保留后台进程 |
| 系统菜单快捷切换 | 在 macOS 顶栏或 Windows 任务栏显示连接入口 |

设置项不可用时，查看下方显示的原因。例如，先开启“开机启动”，才能使用“启动时不显示
窗口”。最后一个受管应用也会说明为什么“停用管理”按钮不可用。

如果选择静默启动，同时又关闭后台运行和系统菜单，重新打开主窗口会变得不方便。调整启动
行为后，至少保留一种可见入口。

## 键盘操作

用 **Tab** 和 **Shift+Tab** 在控件间移动，用 **Enter** 或 **Space** 激活已聚焦的按钮或
复选框。文本编辑器保留自身的编辑快捷键。

用 **Escape** 关闭工作区菜单、原始配置编辑器或远程连接弹窗。编辑连接时关闭工作区菜单，
连接表单会保持打开。正在执行的操作可能暂时阻止弹窗关闭。

输入框支持复制、粘贴、剪切、全选和撤销。在 macOS 上，用 **Option+←/→** 按单词移动，
**Command+←/→** 到行首或行尾，配合 **Shift** 扩展选区；**Option+Backspace** 删除前一个
单词，**Command+Backspace** 删除到行首。Windows 和 Linux 使用 **Ctrl+←/→**、
**Ctrl+Backspace**，以及 **Home/End**。原始配置编辑器中的 **Tab** 保留为缩进。

## 管理应用与插件

打开**设置 → 应用与插件**：

- 每行显示应用名称、来源（“内置适配”或“用户插件”）以及管理状态。
- 用该行的“启用管理”或“停用管理”按钮控制 OcHub 对应用的管理能力，同时影响侧栏与
  系统菜单中的入口。
- 至少保留一个启用管理的应用。停用会保留连接数据和该工具当前的配置文件。
- “打开插件目录”会打开本机 manifest 目录，默认是 `~/.ochub/apps/`。添加或修改 `.toml`
  文件后点击“重新加载插件”，加载错误会在同一页面列出。
- 提供配置 schema 的本地声明式插件会出现在应用导航，使用同一套常用、高级、配置文件和草稿编辑器。
  添加受支持的本地应用只需安装插件，无需修改 OcHub 主程序。
- 插件只获得其声明的能力；没有声明的网络探测、官方登录或特殊维护入口不会自动出现。
  未建模的键会保留，但格式和注释能否原样保留取决于配置格式。
- 修改插件后重新打开编辑器，核对新字段。旧草稿记录插件版本；编辑期间更换适配器时，
  应用会拒绝把旧版本草稿直接写入。
- 远端仅返回字段列表不能提供完整编解码能力；桌面端无法识别的远端插件不开放结构化编辑。
  这与已支持的本地声明式插件不同。

## 切换主题

1. 打开**主题**。
2. 选择“跟随系统”“固定浅色”或“固定深色”。
3. 在主题库中点击“应用”。
4. 跟随系统时，OcHub 会在同一主题的浅色和深色变体之间切换。

## 不同桌面的外观

OcHub 使用本机可用的界面字体和等宽字体。Windows 保留系统模糊背景；Linux 上的模糊主题
使用不透明背景回退，以免窗口后的内容影响文字阅读。显式设置为透明的主题仍保持透明。
Linux 标题栏由桌面环境提供时，应用不会再添加一条重复标题栏。

## 导入、导出与编辑

- 内置主题只读；点击“复制并编辑”创建用户副本。
- 用户主题可以编辑名称、作者、说明、材质、透明度和颜色令牌。
- “更新预览”会临时把整个应用切换到草稿；保存或取消后退出预览。
- 浅色与深色变体必须分别配置，并通过文字、强调色和表面的可读性校验。
- “导出”用于分享主题文件，“导入主题”会校验两个变体后再加入主题库。

编辑颜色时使用完整的 `#RRGGBB`。如果保存提示对比度不足，根据错误中列出的变体和字段
调整前景或背景，直到至少达到 4.5:1。

## 恢复

- 主题预览不满意时点击“取消”，应用会回到预览前的主题。
- 内置主题不能删除。
- 删除用户主题会移除本机主题文件，属于不可撤销操作；需要保留时先导出。
