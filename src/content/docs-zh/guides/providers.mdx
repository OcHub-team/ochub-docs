OcHub 为每个应用分别保存连接。Claude Code 中的连接不会自动出现在 Codex 中，但可以
使用“复制到应用”转换为目标工具的格式。

## 自动发现已有配置

打开应用页面时，OcHub 会尝试读取该工具当前的实时配置：

- 能识别的连接会出现在“直接连接”列表中。
- 已写入工具但尚未设为当前项的连接会显示“已添加”。
- 当前正在使用的连接会显示“当前”。
- 无法完整识别的自定义字段应先查看写入预览，避免重新保存时丢失。

## 连接的日常操作

| 操作 | 适用场景 |
| --- | --- |
| 编辑 | 修改地址、密钥、模型、备注或高级字段 |
| 拖动排序 | 调整列表和系统菜单中的显示顺序 |
| 复制到应用 | 用目标应用的格式另存一份，不改动原连接 |
| 添加到工具 | 预先写入工具，但保持当前连接不变 |
| 切换 | 立即把它设为当前连接 |
| 从工具移除 | 保留 OcHub 数据，只移除工具侧配置 |
| 删除 | 从 OcHub 永久删除连接 |

## 官方登录

“使用官方登录”不会写入第三方 Base URL 或 API Key，而是沿用工具自身的登录状态。适合：

- Claude Code 或 Codex 已完成官方账号登录。
- 临时从第三方 API 切回官方服务。
- 希望保留工具原生的账号和订阅能力。

对于 Codex，`auth.json` 和 `config.toml` 都属于当前连接版本。任一文件在 OcHub 外被修改后，
如果希望保留修改，应在切走前查看差异并保存为新版。

## 应用专属设置

在应用页面右上角打开“应用设置”：

| 应用 | 主要设置 |
| --- | --- |
| Claude Code | 跳过 MCP 引导、Claude 插件集成、自定义配置目录 |
| Codex | 统一会话历史、迁入既有会话、自定义配置目录 |
| OpenCode | 自定义配置目录 |
| OpenClaw | 自定义配置目录 |
| Hermes | 自定义配置目录 |
| Grok Build | 自定义配置目录 |

自定义目录会影响配置、MCP 或会话历史的读取位置。保存后建议重启 OcHub 和目标工具。

目录输入在点击“保存”前属于草稿，切换其他行为开关会保留这段输入。如果保存过程中继续
修改目录，请再点一次“保存”，写入后续输入的内容。

## 编辑器中的检查工具

- **测试 URL**：测量端点返回 HTTP 响应的延迟。
- **拉取模型**：使用当前地址和密钥获取模型列表。
- **查询余额**：仅对实现了余额接口的供应商有效。
- **将写入的文件**：展示保存或切换时生成的配置内容和目标路径。
- **通用配置**：把应用级共享片段合并到启用该选项的连接。

“将写入的文件”支持横向滚动，可查看完整的配置长行。点击“编辑”打开原始配置编辑器，
修改后用“应用”返回连接表单，再保存连接以持久保存这些修改。

测试成功不代表模型一定可调用。最终以目标 CLI 发起的真实请求为准。

## 配置被外部修改

OcHub 会把每个当前连接视为一个已保存的配置版本。切换前，它会比较这个版本与磁盘上的
当前文件：

1. 查看并排文件差异。红色是已保存版本，绿色是当前文件。
2. 选择“保存为新版”，把当前文件存入当前连接后再切换；以后切回来时会恢复这个新版。
3. 选择“回退为旧版”，丢弃磁盘上的当前修改，恢复已保存版本后再切换。
4. 选择“取消”，OcHub 数据和当前文件都不会改变。

该流程适用于所有可读取实时配置的切换型应用，包括 Claude Code、Codex、Grok Build、
Kimi Code 和切换型插件。Codex 会把 `auth.json` 与 `config.toml` 分开展示；即使
`auth.json` 不是合法 JSON，其原始文本也会纳入差异，并可原样保存和恢复。

不要让 OcHub、cc-switch 和手工编辑器同时修改同一份配置。

## 验证新连接

在任何应用中保存或切换连接后：

1. 查看生成的文件与路径。
2. 保存后确认卡片状态是“已添加”或“当前”。
3. 完全重启目标工具。
4. 选择新的 Provider 与模型。
5. 发起一条短请求。
6. 检查工具错误、OcHub 用量或上游日志。

| 问题 | 常见原因 |
| --- | --- |
| 连接没出现在工具里 | 保存后未“添加到工具”，或配置目录不对 |
| 一个连接覆盖了另一个 | 多连接共存应用使用了重复 Provider ID |
| 401 | API Key、环境变量或进程启动环境不一致 |
| 404 / 请求体错误 | API Backend、协议或 API 模式选错 |
| 模型可见但调用失败 | 模型 ID、上下文限制或权限不匹配 |
| 高级字段保存失败 | JSON/YAML 节点类型不正确 |
